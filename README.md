# PaperTrail

PaperTrail turns messy screenshots, PDFs, emails, chat logs, and saved links into a concrete local action plan with deadlines, risks, and a ready-to-send reply.

## Setup

1. `npm install`
2. Create `.env.local` from `.env.example`
3. Add Supabase values: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and optionally `SUPABASE_SERVICE_ROLE_KEY`
4. Run `supabase/schema.sql` in the Supabase SQL editor
5. `npm run dev`

## Supabase data

- Auth uses Supabase email/password login.
- Analysis rows are saved in `public.papertrail_analyses`.
- Uploaded source files are saved in the private `papertrail-uploads` Storage bucket.
- Result pages receive short-lived signed URLs for uploaded files.
- Run `supabase/schema.sql` once before using the app.
- Analysis results are generated by local heuristic parsing rather than an external AI model.

## MVP features

- Paste text or upload an image/PDF
- Turn saved items into a local summary, deadlines, actions, risks, entities, and suggested reply
- Copy reply and track checklist completion
- Reopen previous analyses from Supabase history
- Save uploaded images, PDFs, and text files in Supabase Storage
