# PaperTrail

PaperTrail turns messy screenshots, PDFs, emails, and chat logs into a concrete action plan with deadlines, risks, and a ready-to-send reply.

## Setup

1. `npm install`
2. Create `.env.local` from `.env.example`
3. Add Supabase values: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and optionally `SUPABASE_SERVICE_ROLE_KEY`
4. Add your NVIDIA Build key as `NVIDIA_API_KEY`
5. Run `supabase/schema.sql` in the Supabase SQL editor
6. `npm run dev`

Default routing:

- Text and extracted PDF text: `nvidia/llama-3.3-nemotron-super-49b-v1.5`
- Screenshot/image uploads: `nvidia/nemotron-nano-12b-v2-vl`

If no NVIDIA API key is present, authenticated users can still save analyses generated by lightweight local heuristics for pasted text and extractable PDFs.

## Supabase data

- Auth uses Supabase email/password login.
- Analysis rows are saved in `public.papertrail_analyses`.
- Uploaded source files are saved in the private `papertrail-uploads` Storage bucket.
- Result pages receive short-lived signed URLs for uploaded files.
- Run `supabase/schema.sql` once before using the app.

## NVIDIA Build notes

- PaperTrail uses the NVIDIA Build OpenAI-compatible endpoint.
- Put your serverless API key from `build.nvidia.com` into `.env.local` as `NVIDIA_API_KEY`.
- PaperTrail auto-selects a text model for text-heavy inputs and a vision-language model for screenshots and document images.
- NVIDIA documents `nvidia/nemotron-nano-12b-v2-vl` as a multimodal document-intelligence model for invoices, receipts, manuals, visual Q&A, and summarization.
- NVIDIA documents `nvidia/llama-3.3-nemotron-super-49b-v1.5` as a high-efficiency reasoning model for instruction following and agentic tasks.

## MVP features

- Paste text or upload an image/PDF
- Analyze into summary, deadlines, actions, risks, entities, and suggested reply
- Copy reply and track checklist completion
- Reopen previous analyses from Supabase history
- Save uploaded images, PDFs, and text files in Supabase Storage
